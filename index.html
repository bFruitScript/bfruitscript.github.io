📚 How to Use Scripts

Using an Executor

  1. Download a trusted executor (e.g., Krnl, Synapse X)
  2. Launch your game
  3. Attach the executor to the game process
  4. Copy the script from BFscripts
  5. Paste and execute!

Using an Injector

  1. Download the injector recommended by the script
  2. Run the injector as administrator
  3. Select the game process
  4. Load the script file
  5. Click inject and enjoy!

Key System Scripts

  1. Execute the script in your executor
  2. Copy the key from the popup or console
  3. Visit the key link provided
  4. Complete the verification
  5. Paste the key back into the executor
